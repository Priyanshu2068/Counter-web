# Counter App

A simple counter application built using HTML, CSS, and JavaScript.

## Features
- Increase counter
- Decrease counter
- Reset counter
- Dark/Light theme support

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` in browser
